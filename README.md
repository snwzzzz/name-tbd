# name-tbd

A low-code visual app builder: place widgets on pages, wire them up with workflows, connect them to data, and export the result as a single self-contained HTML file.

## Which branch should I use?

- **`developer`**: a working version of the project.
- **Feature branches**, such as **`feature/production-ready`**: newer functionality. These may be ahead of `developer` but aren't guaranteed to be stable.
